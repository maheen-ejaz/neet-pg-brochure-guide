# Source documents

Official NEET PG counselling documents that every fact in `data/` cites, one folder per authority and year:
`source.pdf` (the document, or several merged in a fixed order), `pages/p-NN.jpg` (one image per page, served by
the review tool) and, where there were several originals, `docs/`.

| Folder | Document |
|---|---|
| `uttar-pradesh/2026/` | UP NEET PG 2026 counselling brochure (scanned, 25 pages) |
| `gujarat/2026/` | 12 current-year notices from the Gujarat admission committee, merged into 81 pages (URLs in `data/states/gujarat-2026.json` → `source.documents`) |
| `karnataka/2026/` | KEA PGET 2026 Information Bulletin (68 pages, 14-08-2026) |
| `mcc/2026/` | MCC tentative NEET PG counselling schedule (4 pages, 07-10-2026) |

These are publications of the respective state counselling authorities and the Medical Counselling Committee.
They're included for reference and citation only, are **not** covered by the repository's MIT licence, and remain
with their publishers. Always check the official website for the latest version.
