# Where this design system is used

This folder is a copy of the "Attio Mono" design system the app is built on. The app's own implementation is
`src/index.css` (Tailwind v4 `@theme inline` tokens, light and dark) and the components in
`src/app/components/ui.tsx`. If the two ever disagree, `src/index.css` is what ships.

Open `cover.html` and `components/*/preview.html` in a browser to see the tokens and components.
The online version linked in `README.md` is a private claude.ai artifact owned by the previous owner;
this folder has the same content.
