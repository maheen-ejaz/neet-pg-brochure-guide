# Citation

A tiny inline tag that names the source of a fact, placed at the end of the sentence it supports.

- `micro` type in `muted` on `canvas`, `radius-sm`, padding 2px 6px, 6px left margin.
- Keep short labels on one line (`white-space: nowrap`); long multi-source labels may wrap.
- The consumer provides the label ("Brochure p. 4", "Eligibility criteria p. 1 · Help centres p. 1").
- Don't: make it look like a button or link unless it opens the source.
